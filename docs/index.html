User Manual

Version: Phase 8 (Advanced UI/UX & Interaction)

1. Introduction

The STM32 Drum Module is a professional-grade 6-channel, 32-step drum sequencer designed for Eurorack modular synthesizers. Powered by the STM32F411 "Black Pill" at 100MHz, it provides reliable audio triggering, low-latency playback, and a premium flicker-free IPS display interface.

Phase 8 Highlights: Direct step count manipulation, high-contrast inverted focus highlights, and "Ghost Step" awareness for professional pattern management.

2. Hardware Setup

Pin Connections

Pin Function Description
PA15 Clock Output 24 PPQN Sync Pulse (Hardware PWM @ 3.3V)
PA1, 2, 3, 4 LCD Control CS (4), DC (2), RESET (3), Backlight (1)
PA5, PA7 SPI1 (LCD) SCK / MOSI (48MHz High Speed)
PB6, PB7 Rotary Encoder Phase A / B
PB8 Encoder Sw Push to edit values/Select precision tempo
PB10, 12, 15 I2S2 (Audio) BCK, LRCK, DIN -> PCM5102A DAC
PB3, 4, 5 SPI3 (SD) SCK, MISO, MOSI -> FAT32 SD Card
PC13 Status LED Blinks to the master clock (Internal LED)

3. Controls & Usage

Transport & Playback

  • Start / Stop: Press the dedicated START button (PA0).
  • Tempo: Turn the encoder to adjust BPM (40 - 300).
  • Precision BPM: Click the encoder (when in Main Mode) to toggle between 1.0 and 10.0 BPM increments.

Direct Step Count Editing

In Pattern Edit (Grid) mode, you can change the pattern length instantly:

  • Navigate: Rotate the encoder to the far left (past Channel 1).
  • Focus: The step count (e.g., "01/32") will highlight with a Cyan background.
  • Edit: Click the encoder button. The background turns Yellow. Rotate to change the length (1-32).

Navigation & Menus

Button Short Press (Click) Long Press (Hold)
DRUMSET Toggle Channel Edit (Volume/Pan) Enter Kit Save/Load Menu
PATTERN Toggle Pattern Edit (Grid) Enter Pattern Management (Save/Load/Clear)
Performance Mode: You can enter all menus and edit both kits and patterns **while the sequencer is playing** without interrupting the audio.

Step Edit Mode (The Grid)

Access the 32-step grid by clicking the PATTERN button while in Pattern Edit mode.

  • Turn Encoder: Move the selection cursor across the 4x8 grid.
  • Click Encoder: Cycle step velocity (OFF -> LOW -> MID -> HIGH -> ACCENT).
  • Playhead: A black indicator square shows real-time playback position.
  • Ghost Steps: Steps outside the current pattern length are dimmed (black background, gray border). Existing data in these steps is preserved but rendered at 25% brightness.

4. SD Card Setup

Format your card as FAT32. The module supports hot-swapping (re-initialization occurs on kit/pattern load).

Directory Structure

/root
  ├── DRUMSETS/
  │   ├── KIT-001.DRM   (Kit config: paths, volume, pan)
  │   └── ...
  ├── PATTERNS/
  │   ├── PAT-001.PAT   (Binary 32-step data)
  │   └── ...
  └── SAMPLES/
      ├── KICK.WAV
      ├── ... (User samples here)
WAV Requirements: 44.1 kHz, 16-bit, Mono PCM.

5. Technical Specifications

  • Engine: 6-Voice Stereo Mixing Engine
  • Output: 44.1kHz / 16-bit via I2S (PCM5102A)
  • Sequencer: 32 Steps per channel (4 bars in 4/4)
  • Sync: 24 PPQN Hardware Clock Output (PA15)
  • Storage: Save/Load 100 Kits and 100 Patterns
  • UI: 320x240 IPS Color Display (Flicker-free Refresh)
